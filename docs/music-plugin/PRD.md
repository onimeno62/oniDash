# oniDash Music Plugin — PRD

## Vision
A beautiful, local-first music library manager, browser, and player for users who own their music.

## Goals
Make large collections easy to browse, provide excellent playback, manage metadata and artwork safely, offer powerful search/filtering, preserve user control over local files, provide useful listening statistics, and feel like a premium desktop application.

## Supported media
Initial formats: FLAC, MP3, AAC, M4A/MP4, OGG/Opus, WAV, and AIFF. The architecture must allow future formats.

## Primary features
Home: continue listening, recently played/added, favorites, most played, discovery, library summary, quick actions, and library health.
Library: tracks, albums, artists, genres, years, folders, compilations, and Various Artists.
Artist/album pages: artwork, metadata, discography, track lists, play/shuffle/queue actions, favorites, and optional provider biography.
Player: persistent mini/full player, play/pause, previous/next, seek, volume, shuffle, repeat, queue, progress, artwork, lyrics integration, and optional gapless/crossfade/ReplayGain.
Playlists: manual playlists, folders, reorder, duplicate prevention, smart playlists, export/import architecture.
Metadata: embedded tags, artwork, provider architecture, matching/correction, and safe editing.
Library management: multiple sources, initial/incremental scans, watch folders, rescan, duplicates, missing-file and malformed-file reporting.
Search: global instant search across tracks, albums, artists, genres, and playlists with fuzzy/prefix matching and filters.
Statistics: totals, listening time, plays over time, top entities, genre distribution, and history.

## Non-goals
Music streaming service, DRM playback, cloud storage, social network, purchasing, and automatic destructive file organization.

## Success criteria
A 50,000-track user can scan without blocking the UI, find content quickly, begin playback in seconds, maintain a persistent queue, manage metadata safely, understand the collection through statistics, and use core functionality offline.
