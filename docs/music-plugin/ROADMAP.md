# Music Plugin Roadmap

1. Foundation: plugin registration, routes, database, sources, scanner, metadata parser.
2. Library: tracks, albums, artists, genres, artwork, search.
3. Playback: audio backend, persistent player, queue, history, favorites.
4. Organization: playlists, smart playlists, metadata editing, duplicate detection, library health.
5. Enrichment: MusicBrainz, Discogs, Last.fm, lyrics abstraction, enhanced artwork.
6. Analytics: dashboard, charts, top artists/albums/tracks, listening calendar.
7. Polish: animation, shortcuts, command palette, virtualization, performance, accessibility, responsive behavior.
8. Advanced: synchronized lyrics, visualizer, waveform preview, equalizer, multi-device output, ratings, mood/energy tags, collection intelligence.

Do not start a later phase while the current phase's acceptance criteria are failing.
