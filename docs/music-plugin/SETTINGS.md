# Music Settings

## Library
Library sources, scan on startup, watch folders, scheduling if supported, and missing-file retention.

## Playback
Default volume, ReplayGain mode, crossfade, gapless playback, playback rate, remember position, and autoplay behavior.

## Appearance
Grid/list defaults, artwork size, compact mode, animations, and system reduced-motion behavior.

## Metadata and search
Write-metadata permission, providers, automatic enrichment, artwork preference, provider rate limits/cache, fuzzy matching, and search result limits.

## Privacy
Listening history and statistics can be disabled.

All settings use oniDash's shared settings infrastructure.
