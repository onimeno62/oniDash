# Architecture Decision Records

## ADR-001 — Local-first
Primary library index is local and useful offline.

## ADR-002 — Modular catalogues
Music, Movies, Anime, Manga, Books and future catalogues are modules/plugins.

## ADR-003 — Web frontend
React/TypeScript is the primary UI for fast visual iteration and reuse across desktop/LAN clients.

## ADR-004 — .NET backend
C#/.NET provides strong Windows/filesystem integration and mature tooling.

## ADR-005 — SQLite initially
Zero-config local database; persistence remains behind application abstractions.

## ADR-006 — Shared visual language
Plugins have catalogue-specific information architecture but use the shared oniDash design system.
