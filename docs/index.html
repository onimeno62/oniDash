Design Philosophy

Engineered for speed, privacy, and sovereignty.

Cloud media servers lock your data inside subscription walled gardens. oniDash treats your filesystem as the source of truth.

✓

100% Local-First & Private

No mandatory cloud accounts, telemetry backdoors, or external tracking. Your media files, playlists, and viewing history remain strictly on your local disk.

⚡

Sub-Millisecond SQLite FTS5

Live incremental database triggers keep an SQLite FTS5 index synchronized with your media. Prefix queries, typos, and fuzzy searches resolve instantly.

⊞

Native Windows Productization

Equipped with global keyboard media keys, system tray life cycle, file association registrations, and one-click full archive backup and migration.

The 4 Core Catalogues

Four distinct mediums. Zero compromises.

Generic players treat every file the same. oniDash embeds specialized domain engines designed around the unique demands of each media type.

Milestone M4 · Audio Subsystem

Hi-Fi Music with ReplayGain & ID3 Tagging

Direct ID3v2, Vorbis Comment, and FLAC tag parsing. Features automatic ReplayGain peak/loudness normalization extraction to eliminate jarring volume spikes across albums.

  • ReplayGain track and album gain persistence
  • Embedded artwork extraction and caching
  • Gapless playback and cue/playlist boundaries

Under The Hood

Multi-Database SQLite Isolation

Instead of cramming every media type into a single shared database that risks lock contention during heavy scanner indexing, oniDash isolates domains into distinct SQLite files.

Core Engine

oniDash.db

Source roots, recursive filesystem entries, file signatures, and FTS5 search index triggers.

Infrastructure/Persistence
Audio Catalogue

music.db

Tracks, album artists, ReplayGain normalization values, playlists, and cover art references.

Music/Persistence
Video Catalogue

movies.db

Movies, TV series, season hierarchies, video probe metadata, and continue-watching state.

Movies/Persistence
Manga Catalogue

manga.db
