# oniDash Screen Specification

## Home
TopBar → greeting → featured/continue → recently added → progress → favorites/catalogue shortcuts.

## Library
Search, sort, filter, view mode, pagination/infinite loading. Grid and compact list.

## Search
Global search with All/Music/Movies/Anime/Manga/Books filters and grouped results.

## Detail
Artwork + title/metadata/actions → description → tags → related content → files. Plugins may add sections.

## Settings
Appearance, Libraries, Plugins, Playback, Metadata, Advanced.

## States
Empty states explain what is empty and the next useful action. Loading uses skeletons matching final layout. Errors provide retry/details/continue.

## Starting catalogue layouts
Music: hero → albums → artists → tracks/playlists.
Movies: continue → recent → genres → favorites.
Anime: continue → series → episodes.
Manga: continue → recent → series → chapters.
Books: continue → recent → authors → books.
