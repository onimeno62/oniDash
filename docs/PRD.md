# Product Requirements Document — oniDash

## Vision
Create a beautiful, extensible Windows media library that unifies local music, movies, anime, manga, books/e-books, and future media collections.

## Goals
- Local-first media management
- Fast discovery and search
- Beautiful artwork-centric UI
- Safe filesystem indexing
- Extensible catalogue architecture
- Consistent experience across catalogues
- Windows-native delivery

## v1 non-goals
Cloud-first storage, streaming-service replacement, destructive automatic organization, social network, AI recommendations, plugin marketplace, and cloud synchronization.

## Core use cases
Add a folder; scan/index it; browse; search; open/play; view metadata/artwork; tag/favorite; collections; progress; modules/plugins.

## Roadmap catalogues
Core → Music → Movies → TV/Anime → Manga/Comics → Books/E-books → future modules.

## Principles
Local-first, non-destructive, modular, fast, visually coherent, accessible, testable, offline-capable, user-owned data.
