# oniDash UX Flows

First launch: Launch → welcome → choose local library location → scan → dashboard. Allow skipping.

Add library: Settings/Library → Add source → folder picker → source name → save → scan.

Scan: show source, discovered/processed counts, progress, errors, cancel. Cancellation preserves completed work.

Browse: Sidebar → catalogue → landing page → filter/sort → media card → detail.

Search: Global search → query → grouped results → detail.

Play/open: Media item → primary action → local file → supported playback strategy → progress where supported.

Plugin installation is later and must include compatibility/permission confirmation.

Principles: one primary action per major surface; avoid unnecessary modals; preserve list context; confirm destructive actions; show background work without interrupting browsing.
