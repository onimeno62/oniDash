# Milestone 01 — Foundation

## Objective
Create a runnable oniDash skeleton with a modern visual shell and clean backend/frontend boundary.

## Deliverables
Backend: .NET solution, Core/Application/Infrastructure/API, health endpoint, DI, configuration, logging, SQLite configuration.

Frontend: React/TypeScript, routing, AppShell, Sidebar, TopBar, content area, theme system, empty/loading states, API health page.

## Acceptance criteria
1. Backend builds with no errors.
2. Frontend builds with no errors.
3. API starts locally.
4. Frontend communicates with API.
5. Shell matches intended oniDash direction.
6. Dark theme is polished.
7. Light theme is usable.
8. Navigation works.
9. Core contains no catalogue-specific logic.
10. Tests pass.

## Not in this milestone
Media scanning, external metadata APIs, music player, movie player, plugins.
